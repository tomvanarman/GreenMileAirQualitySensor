# How to Print

The Green Mile enclosure has been designed for 3D printing. Users can either print the enclosure themselves or use an external 3D printing service. This section explains how to obtain and manufacture the latest version of the design.

There are multiple ways to print this design. In this guide, the easiest method is explained for users who do not have access to a 3D printer. If you have your own 3D printer, you can skip to step 6.

## 1. Download the STL File

You can find the latest STL file in the following directory:

[Download the latest STL file](../assets/design/GreenMileBracket_latest.stl)

Download the latest version of the enclosure.

## 2. Order the Print

There are various online 3D printing services where you can upload your STL file and have it printed and shipped to you.

For example:

[QD-P 3D Printing Service](https://qd-p.com/3d-printen/calculator)

Upload the file, choose your preferred material (PLA is a good standard choice), and select the desired quality and color. After that, you can place your order.

## 3. Check Your Settings (Recommended)

Before ordering, make sure:

- The model is scaled correctly.
- The walls are thick enough for printing.
- No parts are floating or broken.
- The selected material meets the requirements of the project.

Most printing services will check this automatically, but it is recommended to verify it yourself.

## 4. Receive and Assemble

Once the print arrives, you can assemble the components. Some parts may require additional steps, such as:

- Installing threaded inserts.
- Removing support material.
- Cleaning up small imperfections.
- Mounting the electronic components.

## 5. If You Do Not Have a 3D Printer

If you do not own a 3D printer, continue following the steps above. Once the printed part arrives, you can proceed with the assembly of the enclosure.

## 6. If You Have Your Own 3D Printer

Open the software that is compatible with your 3D printer, such as:

- Bambu Studio
- PrusaSlicer
- Ultimaker Cura

## 7. Upload the STL File

Import the STL file into your slicing software.

[Download the latest STL file](../assets/design/GreenMileBracket_latest.stl)

After importing the file, verify that the model is positioned correctly on the build plate and that the scale is correct.

## 8. Configure the Print Settings

Configure the print settings according to your printer and the selected material.

Recommended settings:

- Material: PLA
- Layer Height: 0.2 mm
- Infill: 15–20%
- Supports: Enabled if required
- Build Plate Adhesion: Enabled

Always review the print preview before starting the print.

## 9. Start Printing

Generate the G-code file and send it to your printer using an SD card, USB connection, or wireless transfer.

Start the print and monitor the first few layers to ensure proper bed adhesion. Once the print has completed, carefully remove the part from the build plate.

## 10. Post-Processing and Assembly

Remove any support material if present and clean the printed part if necessary.

The enclosure is now ready for assembly and installation of the Green Mile Air Quality Sensor components.
